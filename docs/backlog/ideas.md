# Backlog

Ідеї, які свідомо не впроваджуємо зараз. Агент додає записи за правилом `.cursor/rules/backlog.mdc`.

## Google OAuth

**Дата:** 2026-08-20

**Суть:** Клієнт Google OAuth створено. Ключі в `.env` / `.env.local` (`NEXT_PUBLIC_GOOGLE_AUTH=true`). Redirect: `http://localhost:3000/api/auth/callback/google`. Перед продом додати production origin + callback.

**Статус:** Готово до впровадження

## Stripe checkout

**Дата:** 2026-08-20

**Суть:** Онлайн-оплата як у e-commerce не підходить для продажу авто. Stripe, `/checkout`, `/api/payment`, `/api/confirm` видалені. Кошик лишився як залишок шаблону до адаптації під авто.

**Статус:** Скасовано

## Кошик по категоріях товарів

**Дата:** 2026-09-09

**Суть:** Авто 50K+ не продаються checkout-ом, але кошик залишаємо як інфраструктуру для майбутніх витратних матеріалів / мастил. У адмінці потрібен перемикач: увімкнути/вимкнути кошик для конкретної категорії товарів.

**Статус:** Відкладено
