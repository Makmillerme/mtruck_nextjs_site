# Homepage finder roots as fill plates (2026-10-07)

Catalog roots row (`showRoots` / `catalogLabel`) uses `FinderFolderCard` `tone="fill"` (same compact fill plates as former L2 types), not pill chips.

Child row (subtypes under selected root) uses outline plates (default tone). Grandchildren stay outline + `border-l` indent.

Brand/facet chips still use `chipClass`.
