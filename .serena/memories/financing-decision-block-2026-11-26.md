Financing calculator left column has a decision sub-block under the sliders.

Desktop grid: controls are col 1 row 1, quote spans col 2 rows 1–2, the decision block is col 1 row 2 (under the sliders, beside the quote). On a single column the order is controls, quote, then the block.

Block: heading «Отримати рішення», one line of the current quote (mode, down %, term, monthly), full-width primary Button via CtaInquiryTrigger. Opens the existing callback dialog. The message is prefilled with that line (CtaInquiryContextValue.note → ContactForm defaultNote) and the buyer can edit it. Product page passes productId/name/code. UI Lab uses the same calculator without a product, so the dialog still opens.

Keys: Product.financingDecisionTitle, financingDecisionSummary (uk/en/de).

Do not stretch the sliders to fill the column. The block sits in the space under the control group.
