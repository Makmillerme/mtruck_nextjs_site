## Замовлення кабінету (2026-09-14)

- `Order.origin`: `USER` | `ADMIN` (default ADMIN для старих рядків).
- Каталог 1-клік і кабінетний REQUEST → `USER`. Адмін CRUD → `ADMIN`.
- Кабінет `/account/orders`: той самий тулбар що продажі (пошук + «Створити», без фільтра оплати). Створення = індивідуальний REQUEST (папка + коментар), без вибору авто в кабінеті.
- Олівець у кабінеті для будь-якого власного замовлення зі `status=NEW` (старі 1-клік рядки мали origin ADMIN і комірка «Дії» була порожня). IN_PROGRESS/CLOSED — без edit. CATALOG: авто read-only, коментар. REQUEST: папка + коментар.
